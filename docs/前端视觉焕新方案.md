## 1. 现状诊断（为什么值得焕新）

当前界面（`style.css` + `App.vue`）是"毛玻璃亮色 + 蓝色强调"的通用中后台风格，功能完整但视觉语言偏默认：

| 维度 | 现状 | 问题 |
|---|---|---|
| 导航图标 | emoji（🚁📟📋🚨📊） | 与整体精致度不匹配，不同系统渲染不一致 |
| 字体 | Segoe UI / Microsoft YaHei | 无数字等宽（tabular-nums），状态数字跳动；无品牌感 |
| 色彩 | 单一蓝 #2f6fed + 语义色 | 缺少层级：主色/强调/图表色未形成体系，ECharts 用默认色板 |
| 组件 | 手写 card/badge/button/table | 无 hover 层次、无骨架屏、无空状态设计 |
| 地图 | Leaflet 默认 OSM 彩色底图 | 底图色彩喧宾夺主，设备标记是简单 divIcon |
| 状态反馈 | 原生 alert（登录失败等） | 破坏沉浸感 |
| 页头 | 纯文字标题 + 分隔线 | 无页级操作区（如时间范围、刷新频率、全屏） |

**结论**：不需要推翻重来——布局骨架（侧边栏 + 内容区）是合理的，缺的是一套**设计令牌 + 图标体系 + 图表主题 + 地图风格**的系统性升级。

## 3. 四条风格路线（三选一或组合）

| 路线 | 定位 | 色板核心值 | 优势 | 风险 | 工作量 |
|---|---|---|---|---|---|
| **A 亮色精修** | 现有风格打磨到专业水准 | 背景 #F7F8FA / 卡片 #FFF / 主色 #2563EB / 文字 #1F2937 | 风险最低、与报告截图兼容 | 提升幅度有限 | ★☆☆ |
| **B 暗色 2.0** | 克制的指挥中心（Linear 式中性灰） | 背景 #0F1720 / 面板 #1A2433 / 强调 #38BDF8 / 文字 #E6EDF5 | 气质贴合"巡检监控" | S94 曾被用户弃用，需先小样确认 | ★★☆ |
| **C 双主题 Token 化**（推荐） | 一套代码，右上角一键亮/暗切换 | 路线 A + B 各一套 CSS 变量 | 一次改造长期受益；答辩可现场切主题展示工程能力 | 需要全部颜色走变量，改造最彻底 | ★★★ |
| **D 数据大屏 `/wall`** | 投屏演示专用增量页面 | 背景 #061428 / 面板 #0A1F3C / 青 #00D4FF / 点缀 #FFB020 | 纯增量不动现有页面，答辩视觉冲击最强 | 多维护一个页面 | ★★☆ |

**建议组合**：**C 为骨架（Token 化），D 为增量（大屏）**。理由：
1. C 让"亮色精修（A）"和"暗色指挥中心（B）"都成为 Token 的两个取值，S94 的成果思路可在暗色 token 里以更克制的方式复用；
2. D 不碰业务页面，风险隔离，且课程答辩"投大屏"是强演示场景；
3. 报告 5.4 截图仍可用亮色主题截取，风格叙事完整。

## 4. 设计令牌清单（路线 C 的具体值）

建立 `web/src/styles/tokens.css`，所有颜色一律走 CSS 变量，`:root` 为亮色，`[data-theme="dark"]` 覆盖：

```css
:root {
  /* 色面 */
  --bg-page: #f7f8fa;        /* 页面底 */
  --bg-card: #ffffff;        /* 卡片 */
  --bg-hover: #f0f3f8;       /* 行悬停 */
  --bg-sidebar: rgba(255,255,255,.85);
  /* 文字四级灰阶 */
  --text-1: #1f2937;  --text-2: #4b5563;  --text-3: #9ca3af;  --text-4: #c3cad4;
  /* 品牌与强调 */
  --accent: #2563eb;  --accent-hover: #1d4ed8;  --accent-soft: rgba(37,99,235,.10);
  /* 语义色（中文语义：涨红跌绿不适用此处，为状态语义） */
  --ok: #16a34a;  --warn: #d97706;  --danger: #dc2626;  --info: #0ea5e9;
  --ok-soft: #e8f7ee;  --warn-soft: #fdf3e0;  --danger-soft: #fdeaea;
  /* 图表 7 色板（ECharts 主题同步使用） */
  --chart-1: #2563eb; --chart-2: #0ea5e9; --chart-3: #16a34a; --chart-4: #d97706;
  --chart-5: #8b5cf6; --chart-6: #ec4899; --chart-7: #14b8a6;
  /* 形状与阴影 */
  --radius-1: 8px;  --radius-2: 12px;
  --border: #e5e9f0;  --border-strong: #d3dae4;
  --shadow-1: 0 1px 3px rgba(16,24,40,.06);
  /* 字体 */
  --font-sans: "Inter", "HarmonyOS Sans SC", "MiSans", "Microsoft YaHei", sans-serif;
  --font-mono: "JetBrains Mono", "Cascadia Code", Consolas, monospace;
}
[data-theme="dark"] {
  --bg-page: #0f1720;  --bg-card: #1a2433;  --bg-hover: #223047;
  --bg-sidebar: rgba(15,23,32,.88);
  --text-1: #e6edf5;  --text-2: #a8b6c8;  --text-3: #64748b;  --text-4: #3b4a5e;
  --accent: #38bdf8;  --accent-hover: #7dd3fc;  --accent-soft: rgba(56,189,248,.12);
  --ok: #34d399;  --warn: #fbbf24;  --danger: #f87171;  --info: #38bdf8;
  --ok-soft: rgba(52,211,153,.14);  --warn-soft: rgba(251,191,36,.14);  --danger-soft: rgba(248,113,113,.14);
  --border: #26334a;  --border-strong: #33425e;
  --shadow-1: 0 1px 3px rgba(0,0,0,.4);
}
```

**配套约定**：
- 数字一律 `font-variant-numeric: tabular-nums`，关键 KPI 用 `--font-mono`；
- 阴影只用 `--shadow-1` 一档（Linear 原则：分区靠边框，不靠阴影）；
- 圆角全局统一 8/12 两档，禁止混用 4/6/10/16。

## 7. 风险控制（全部来自本项目已登记教训）

1. **bind 挂载陷阱**：`web/dist` 是 bind 挂载，改完必须重建前端，否则线上仍是旧产物（S95 实锤）；
2. **先目视再铺开**：暗色路线必须先出小样经用户浏览器确认，S94 整版做完被弃的教训；
3. **底图降级保守**（风险 #48）：一次性 tileerror 即永久回退是错的，连续 3 次才降级；
4. **截图顺序**：视觉定稿前不得做 S65 截图，否则 17 张图作废（S94 登记过的顺序约束）；
5. **验收方法论**（风险 #49）：无头 Edge 截图 + 像素统计 + DOM 转储自证主题生效，不依赖肉眼；
6. **回滚保险**：开工前打快照 tag（`backup-20260921-s97-pre`），分支开发 `feature/s97-visual-refresh`，每小步提交；
7. **报告同步**：视觉焕新完成后报告 5.2.7 与 `docs/截图操作清单.md` 需同步底图/主题口径（文档升版 v1.3）。

## 8. 答辩加分点（视觉焕新不止是好看）

- **设计令牌工程**：CSS 变量 + 双主题一键切换 = 可讲的"主题工程化"实践（对标 Ant Design 5 Token 思想）；
- **图表主题化**：ECharts 注册主题、色板与语义色一致 = 数据可视化的系统性；
- **地图可视化**：CARTO 低饱和底图 + 状态色标记 + 轨迹渐隐 = "为数据而设计的地图"；
- **无障碍细节**：文字四级灰阶对比度、`tabular-nums`、焦点环，都是可展示的素养点。
