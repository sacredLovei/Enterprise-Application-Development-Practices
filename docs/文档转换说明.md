**重新生成步骤**（PowerShell，工作区根目录）：

```powershell
# 0) 依赖（仅首次；tools/md2html/node_modules 不入库）
cd tools\md2html
npm install marked --registry https://registry.npmmirror.com
cd ..\..

# 1) Markdown -> HTML
node tools\md2html\convert.js "课程设计报告_第2-6章_园区安防巡检平台.md" "课程设计报告_第1-7章_园区安防巡检平台.html"

# 2) HTML -> DOCX（自动校验：段落数/表格数一致 + 标记字符串命中）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\md2html\to-docx.ps1 `
  -Html "课程设计报告_第1-7章_园区安防巡检平台.html" `
  -Docx "课程设计报告_第1-7章_园区安防巡检平台.docx" `
  -VerifyCodes "32479,19968,24322,24120,22788,29702"      # "统一异常处理"
```

**S91 踩坑记录（已修复，勿重犯）**：

1. **Word COM 按自己的当前目录解析相对路径**——脚本里若把相对路径交给 `SaveAs2`，产物会静默落到 `C:\Users\<用户>\Documents\` 而不是工作区；且脚本开头的"删除同名旧文件"已先删掉了工作区副本 → **交付物凭空消失**。修复：`to-docx.ps1` 内部一律转绝对路径（`$DocxAbs`）。
2. **Word COM 可能残留不可见实例**（脚本异常退出或上一实例未退干净时），随后再次转换会卡死（本轮出现一次 5 分钟无响应）。修复：转换前用 `Get-Process WINWORD` 确认无残留；卡死后 `Stop-Process -Id <pid> -Force` 清理再重试。
3. **超时保护**：转换耗时约 10~30 s，但首次运行可能因残留实例阻塞；建议在后台任务中运行，避免被命令超时中断。
4. **校验不依赖 Word**：docx 本质是 zip，可直接解包 `word/document.xml` 统计段落/表格并检索中文标记，避免"打开 Word 才能确认"的脆弱验证。
